# Fifty Festival

Fifty Festival is a small, static music festival landing page built with HTML, CSS, and vanilla JavaScript.

> This is an imaginary concept site for demonstration purposes. It is not an official festival website, and the event details and lineup are fictional.

## Run locally

Open [index.html](index.html) in a browser, or serve this folder with any static web server.

## Project structure

- `index.html` - page content and festival sections
- `style.css` - core layout, colors, typography, intro, festival days, marquee, and responsive styles
- `fonts.css` - local font-face definitions and font assignments
- `shapes.css` - decorative circles and squiggles used across festival sections
- `viewport.css` - fade-in transitions for content as sections enter the viewport
- `footer.css` - registration form, footer, and related decorative elements
- `script.js` - marquee, animations, and smooth scrolling
- `assets/` - images and fonts used by the page
